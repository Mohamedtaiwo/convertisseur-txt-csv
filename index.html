Transformer un fichier texte en fichier Excel

Choisissez un fichier .txt : vous récupérez un fichier .csv qui s'ouvre dans Excel, avec une colonne par information, ou un tableau croisé dynamique prêt à l'emploi.

Votre fichier reste sur votre ordinateur. Rien n'est envoyé ni conservé. La transformation se fait ici même, dans votre navigateur.

    C'est fait !

    Le fichier a été téléchargé.

    Pour l'ouvrir avec Excel, cliquez dessus dans la liste des téléchargements de votre navigateur, ou double-cliquez dessus dans le dossier Téléchargements.

    Ouvrez-le avec Excel : le tableau croisé est sur la première feuille, vos données sur la feuille « Données ». Si Excel affiche un bandeau « Mode protégé », cliquez sur « Activer la modification » : le tableau croisé se remplit.

    Il est au format CSV standard, prévu pour d'autres logiciels qu'Excel. Pour Excel, cliquez sur « Recommencer » et gardez le choix « Excel (recommandé) ».

    Si vous aviez déjà transformé ce fichier, le nouveau porte un numéro, par exemple «  ». Sur téléphone ou tablette, cherchez-le dans l'application Fichiers.

    Par sécurité, les données ont été effacées de cette page.
